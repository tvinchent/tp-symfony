# Kit pédagogique - 5 TP Symfony Bac+2 (10 heures)

Contenu : `ENONCES_TP_SYMFONY_BAC2.pdf`, cinq dossiers `TP1` à `TP5` contenant chacun `README.md` et `starter/`.

Les dossiers `starter/` sont des **surcouches pédagogiques**, pas des projets Symfony installés. Les copier dans une installation Symfony standard selon les instructions de chaque README. Composer doit être disponible sur la machine étudiante.

Ordre conseillé : TP1 (1 h 30) > TP2 (2 h) > TP3 (2 h 30) > TP4 (2 h) > TP5 (2 h).

TP5 est indépendant de la réussite du TP4 : il contient déjà entités + repositories + contrôleur de lecture + fixtures.

**Attention :** les projets sont des supports étudiants, pas des corrigés. Certaines routes afficheront explicitement `TODO` tant que les étudiants n'auront pas travaillé.

Version cible : Symfony stable compatible PHP 8.2+ ; syntaxe ORM par attributs PHP. À l'installation, Composer résout les versions compatibles. Vérifier le prérequis PHP de la version exacte installée.
